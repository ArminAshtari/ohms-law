OHMS LAW CALCULATOR 

A small C++ project for practicing the implementation of mathematical and physics formulas through code.
This project is part of my ongoing C++ learning journey, and I plan to expand and improve it as I learn new concepts.

The program usses the V = I*R (Ohms Law)

The program is set to calculate V(voltage), R(resistance), I(current) 
The user selects what it wants to caluclate and gives the other two values.
